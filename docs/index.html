Octane Comp — ACES

A real-time GPU compositing tool that integrates Octane render passes (Beauty, Diffuse, Reflection, Shadow, Cryptomatte) over Fujifilm F-Log2 footage, in a strict ACES pipeline driven by OpenColorIO 2.

  • F-Log2 F-Gamut → ACEScg, linear compositing, then the ACES 2.0 Output Transform (sRGB).
  • The colour shaders on this page are generated by OpenColorIO, exactly like in the desktop app (Python, PySide6, ModernGL).
  • Reflection gain and shadow density, isolated with Cryptomatte mattes (picker), A/B inspection, wipe and difference views.
  • The desktop app reads multi-layer EXRs, saves settings as JSON and renders 900 frames offscreen to half-float EXR, 16-bit TIFF or ProRes, matching the viewer.

Demo: a synthetic scene built for the occasion. In the browser the passes travel inside an 8-bit, log-encoded video, so precision is a bit lower than the desktop app's float EXRs.

Shortcuts: Space play · ← → step · 1/2 A/B · W wipe · D diff · F fit · wheel zoom · Alt+drag pan.
