Octane Comp — ACES

Outil de compositing GPU temps réel : il intègre des passes de rendu Octane (Beauty, Diffuse, Reflection, Shadow, Cryptomatte) sur un rush Fujifilm F-Log2, dans un pipeline ACES strict piloté par OpenColorIO 2.

  • F-Log2 F-Gamut → ACEScg, compositing en linéaire, puis Output Transform ACES 2.0 (sRGB).
  • Les shaders de couleur de cette page sont générés par OpenColorIO, comme dans l'application de bureau (Python, PySide6, ModernGL).
  • Dosage des reflets et de la densité d'ombre, limité par masque Cryptomatte (pipette), inspection A/B, wipe, différence.
  • L'application de bureau lit les EXR multi-passes, enregistre les réglages en JSON et rend 900 frames hors écran en EXR half, TIFF 16 bits ou ProRes, conformes à l'aperçu.

Démo : scène de synthèse générée pour l'occasion. Dans le navigateur, les passes voyagent dans une vidéo 8 bits (encodage log), donc un peu moins de précision que les EXR de l'application de bureau.
